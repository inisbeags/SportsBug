# SportsBug prototype

Small floating Windows score widget for followed teams. No notifications, account, browser window, or local server.

## Run on Windows

1. Install Python 3.10 or newer from python.org and check **Add Python to PATH**.
2. Unzip this folder anywhere, open PowerShell in the `sportsbug` folder, and run:

   ```powershell
   py -m pip install -r requirements.txt
   py sportsbug.py
   ```

   For subsequent launches, **double-click `Launch SportsBug.pyw`** to open the widget without a command window. If `.pyw` files are not associated with Python on your PC, run `pyw "Launch SportsBug.pyw"` or make a Windows shortcut that runs that command. Keep the extracted folder; there is no installer yet.

Drag the empty area of the header to move the window. Drag the **very bottom edge** down to show more event rows, up to the bottom of the screen, or up to make the widget shorter. Event rows stay the same height; extra window space stays below them. The window stops shrinking when the first row fits completely, without showing part of the next one. Use the mouse wheel to scroll through extra rows; the scroll bar is hidden. The latest check time is at the bottom right. **Right-click the widget** for Refresh, Settings, or Quit SportsBug. `↻` refreshes immediately. With no live event the widget checks every 12 hours, but also wakes shortly before a known event begins. A live game or an F1 session's scheduled time window triggers checks every minute. `⌄` expands the list for per-event spoiler controls. `◎` toggles global spoiler mode; in expanded view, the dot beside an event reveals or hides just that result. `⚙` opens the searchable favorites picker, background color, opacity, snapping, and always on top. The widget saves settings, including window height, in `%USERPROFILE%\SportsBug\settings.json`. It does not start with Windows.

To update an existing copy: close SportsBug, extract this ZIP over the old files, then run `py sportsbug.py` again. Your saved settings are kept. The requested starting favorites are added once; you can remove any in Settings.

The header's **○ / ●** button switches Always on top off/on. Hover over it to check its state. Every header button has a fixed-size slot, so the icons stay in place when toggled. SportsBug uses normal Windows taskbar minimize/restore behavior: clicking its taskbar icon while it is active minimizes it; clicking again restores and brings it forward. The widget keeps updating while minimized.

Soccer team schedules can supply scores as objects or as references to a separate ESPN score request. SportsBug reads numeric objects and tries that score request for live/final matches. Unavailable results display **Final · score unavailable**, and saved results from older releases no longer show raw reference text.

Result badges use W/L/T (Win/Loss/Tie) in a fixed 22-pixel column at the far right of every event, after scores and any reveal button. Scores occupy a fixed-width column immediately to its left. Hover over a badge for its full meaning. The soccer label is **SOC**. Shootouts display the match score and penalty score together (for example **0–0 · PK 4–5**), with **FINAL** below. Overtime and extra innings use compact final labels such as **FINAL · OT** or **FINAL · 11 IN** when the feed provides that detail. Upcoming fixtures show only their date/time. A final with no score displays **FINAL · —**; hover for the full explanation.

Both US and Japan senior men's teams now have independent ESPN friendly team-schedule checks. Japan's October 1 Kirin Cup result against Ecuador is also included as a dated JFA-confirmed backup: 0–0, Japan won 5–4 on penalties. The row shows **FINAL · PK 4–5** in away/home order and a **WIN** tag for Japan. Shootout scores determine WIN/LOSS when known; match scores remain 0–0. This backup expires after three days; youth national teams remain excluded. ESPN can still omit competitions or reject requests, so future national-team coverage is not guaranteed.

## Scope of this first prototype

- Searchable selection of all NFL, NHL and MLB teams, plus Washington and Arkansas football, men's basketball and baseball, Central Washington football, and F1 events. Seattle Seahawks, Seattle Mariners, Seattle Kraken, Cleveland Browns, Washington, Arkansas and Central Washington are preselected. The ESPN college score feed can return HTTP 403; SportsBug also tries an NCAA scoreboard feed for FBS Washington and Arkansas and Division II Central Washington.
- Kawasaki Frontale (J1) and Seattle Sounders (MLS) are preselected and use the soccer scoreboard feed. Seattle Seawolves use TheSportsDB's team schedule and completed results; live tracking is not provided by this source. Seattle Orcas (Major League Cricket) and Geelong Cats (AFL) remain saved favorites with feeds pending.
- United States and Japan **men’s soccer** national teams are preselected for World Cup and international friendly scoreboards. Other competitions are not yet covered. United States, Japan, and Ireland men’s rugby, plus United States and Japan national baseball, are preselected favorites with feeds pending; they will not show live events yet.
- National-team event rows identify the sport: **SOCCER** for US and Japan soccer, with **BASEBALL**, **RUGBY**, or **HOCKEY** for those national feeds when available. Older saved international soccer results also display as SOCCER. Live scores and game periods are green; final scores and FINAL/status text are warm gold; upcoming games keep the regular pale text. The gold result treatment is hidden in spoiler mode.
- A scored final with exactly one followed team gets a compact **WIN** (mint), **LOSS** (coral), or **DRAW** (gray) tag beside its gold score. Finals without a score, games with two followed teams, and tied shootouts with no confirmed winner get no tag. Spoiler mode hides result tags until that game is revealed.
- A header refresh button triggers an immediate update. Automatic refresh runs once a minute during live games or an F1 session window, otherwise every 12 hours or just before the next known event, whichever is sooner. A separate 30-second clock check catches overdue refreshes when the PC resumes from sleep or the window becomes active. If an NHL live feed fails, its old live row changes to **Update unavailable** while automatic retries continue, rather than continuing to claim the game is live. Requests run off the UI thread. Feed errors are shown in Settings under **Feed status**.
- Live favorites appear first, and only the live game appears for that team. At most **one upcoming game per followed team** appears, if it starts within seven days. As soon as the live game is marked final, its result and the next eligible upcoming game can both appear. The final stays for three days after its estimated finish, unless that team's next game goes live first. Feeds rarely provide an exact finish time: while running, SportsBug uses the time it first observes the final; after a restart, it estimates the finish from the scheduled start (typically 2–3½ hours later). A result already past the three-day window will not reappear.
- Drag the bottom grip to choose how many events are visible at once. The window remembers its height, and the event list scrolls when needed.
- NFL, college sports and soccer use ESPN's undocumented scoreboard endpoints, which may change. Sounders and Frontale also check their ESPN team schedules to pick up matches missing from the league scoreboard; if both ESPN endpoints fail, their games cannot be displayed. MLB uses MLB StatsAPI and shows teams by abbreviations (for example, HOU @ SEA). Live games show the available quarter, period, half or inning in green; otherwise green LIVE. F1 qualifying, sprint and race start times use the Jolpica F1 season schedule. Only the next F1 session appears: qualifying stays for two hours after its scheduled start, then the race appears; the race stays for four hours after its scheduled start. Sprint qualifying also uses two hours, while the sprint race uses one hour. During these assumed windows, the label says **Scheduled session**; this schedule feed cannot confirm the actual finish or show live timing, results or driver standings.
- Confirmed Sounders vs Sporting KC (October 2, Japan time) and Kawasaki at Kumamoto (September 29, Levain Cup) have temporary schedule-only entries. These show only before kickoff, and a score feed takes precedence. Additional cup games need feed coverage or another schedule update.
- Temporary verified fixtures also cover Sounders vs Minnesota and USA vs Peru on September 27 (Japan time), Frontale at Kumamoto on September 29, plus USA vs Chile on September 30. The Sounders game is confirmed final without a verified score; USA vs Peru is recorded as 4–1 from a match report; Frontale beat Kumamoto 1–0 in the cup, per the J.League match report. These dated backups expire from display after three days. During an unconfirmed match window, the widget says the score is unavailable rather than calling it LIVE. The US men's team also gets an ESPN friendly team-schedule check; that feed is still subject to ESPN availability. Upcoming events on the computer's current local calendar day display **Today · HH:MM**; other upcoming dates keep the day and month.
- NHL games use the NHL's own team schedule feed, including live scores when provided. If a game reaches its scheduled start before the NHL feed marks it live, it stays visible as **Awaiting puck drop** for up to four hours and is checked every minute; the label does not imply the game has begun. NFL tries ESPN for live scores and separately checks the nflverse game schedule even when ESPN returns no matching game. Around a followed game the cached nflverse schedule is refreshed hourly, and scored games are marked final after the five-hour game window; the schedule is not a live feed and may update later. After kickoff, an unscored schedule-only row stays for up to five hours as **Game window · score unavailable**, checked every minute. The September 27 Seahawks at Commanders (31–33) and Panthers at Browns (18–21) final scores are included as dated, team-verified backups, visible for up to three days. Settings → Feed status keeps any NFL feed errors visible.
- The college football fallback contains confirmed September 26, October 3, and selected October 9–10, 2026 start times from the schools' published schedules. It shows at most one upcoming game per school within seven days. Once a scheduled game starts, it holds that team's row for up to five hours as **Game window · score unavailable** unless ESPN or the NCAA scoreboard confirms live or final status. The FBS and Division II NCAA checks are independent, and each checks the current and previous scoreboard weeks for final results. It does not label the game LIVE from kickoff time alone. The next game for that school appears when the score feed marks the current one final, or after the five-hour window if no result arrives. Additional kickoff times require a future schedule update; a game with a time still listed as TBD is not shown. Feed failures remain visible in Settings under **Feed status**.
- If a feed fails, open Settings and copy the details from **Feed status**. If every ESPN feed fails while MLB works, the exact error can distinguish a network block, HTTP rejection, or response format change.
- NPB: all 12 clubs are selectable. Schedules and published final scores come from the free Nippon Baseball Data Repository release CSV; existing Hanshin/Hiroshima selections migrate automatically. After kickoff an unconfirmed game stays as “Match window / No score yet” for up to eight hours, suppressing its teams’ next games. Only source-confirmed completed games with scores become finals. This is not verified live tracking: final results can arrive later than the actual finish. Cancelled fixtures are omitted. Settings links to the source attribution. Central Washington basketball/baseball and the other pending leagues remain pending.
- Spoiler mode suppresses score and status details that can disclose a result. It does not show standings, winner colors, or notifications. Reveals persist across restart; turning global spoiler mode off resets individual reveals.
- Local start times use your Windows time zone. Logo downloads, custom team search, and an executable installer are later features.

Settings includes a background color picker and Reset color button. Color and opacity are saved independently. Long row text scales down to fit without changing row height; unconfirmed match windows use “Match window / No score yet,” with the full feed status available on hover.

## Desktop and taskbar icon

SportsBug now uses the selected scoreboard bug icon (concept B), refined with taller proportions and a bright head outline for taskbar visibility. Keep SportsBug.ico alongside the application files. To add it to a desktop shortcut: right-click Launch SportsBug.pyw → Show more options if needed → Send to → Desktop (create shortcut). Right-click the new shortcut → Properties → Change Icon → Browse → select SportsBug.ico from the extracted folder → OK → Apply. If Windows warns the launcher contains no icons, dismiss that message and browse to SportsBug.ico. Relaunch the app to update its taskbar icon; an old pinned shortcut may need to be unpinned and recreated.

## Updates and installer

Settings contains Check for updates, a GitHub repository field, and Automatically check for updates on launch. See GITHUB-SETUP.md for the one-time repository and installer build steps. This source ZIP is not yet a compiled installer.

Favorites are grouped as Sport → League → Teams. Search includes team, sport and league and expands matching branches. Pending teams stay selectable and are labeled pending; selecting them does not enable an unavailable feed. See FEED-REVIEW.md for the required release coverage review.

At 00:01 local time each day, SportsBug redraws date labels and requests a feed refresh. The existing 30-second clock checks the deadline and catches up after sleep. Date labels update even if a feed fails.
